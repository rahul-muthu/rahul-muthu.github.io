In Praise of Boring Interfaces

Published 2026-04-11 · 2 min read

The best interface for a repeated task often feels unremarkable. It uses familiar words, preserves state in obvious places, and makes important operations available without ceremony.

Predictability compounds

A small surprise costs little once. A small surprise encountered twenty times each day becomes part of the job. Stable conventions reduce that tax:

  1. Names describe outcomes rather than implementation details.
  2. Defaults are safe and useful.
  3. Errors explain what happened and what to do next.
  4. Automation uses the same model as the human interface.

This is not an argument against ambitious tools. It is an argument for spending novelty where it improves the task.

A test

Watch someone return to the tool after a month away. If they can predict where their work is, what an action will do, and how to undo it, the interface has done something important.
