Odd Fibonacci Sums

Published 2026-07-17 · Updated 2026-07-18 · 3 min read

The Fibonacci sequence begins with F0 = 0, F1 = 1, and the recurrence

Fn = Fn−1 + Fn−2.

The identity

Theorem. For every positive integer n,

∑nk=1 F2k−1 = F2n.

The left side adds the odd-indexed terms. The right side says the entire sum collapses to one even-indexed term.

Proof

The case n = 1 is immediate. Suppose the result holds for n. Then

sum(k = 1 ... n + 1) F(2k - 1)
= sum(k = 1 ... n) F(2k - 1) + F(2n + 1)
= F(2n) + F(2n + 1)
= F(2n + 2)

The second line uses the induction hypothesis and the third uses the Fibonacci recurrence. This proves the claim.1
